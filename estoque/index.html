Configurar Painel na Nuvem

Configure uma vez e acesse seu estoque de qualquer aparelho, com sincronização automática.

1 Criar conta gratuita no Supabase

O Supabase é um banco de dados na nuvem (plano gratuito: 500 MB e 50.000 leituras/mês — suficiente para uso empresarial de pequeno/médio porte).

  • Acesse supabase.com → Start your project.
  • Crie a conta (pode usar GitHub) e clique em New project.
  • Dê um nome, escolha a região mais próxima e clique em Create new project (≈2 min).

2 Criar as tabelas no banco

No painel: SQL Editor → New query. Cole o código abaixo e clique em Run. Ele cria as tabelas produtos e empresa, libera o acesso e ativa a sincronização em tempo real. Pode rodar mais de uma vez sem erro (é idempotente).

-- ===== Tabela: produtos =====
create table if not exists produtos (
  id uuid primary key default gen_random_uuid(),
  nome text not null,
  quantidade integer not null default 0,
  minimo integer not null default 0,
  categoria text default '',
  criado_em timestamptz default now(),
  atualizado_em timestamptz default now()
);

-- colunas novas (nao faz nada se ja existirem)
alter table produtos add column if not exists sku text default '';
alter table produtos add column if not exists fornecedor text default '';
alter table produtos add column if not exists preco_custo numeric(12,2) default 0;
alter table produtos add column if not exists preco_venda numeric(12,2) default 0;

alter table produtos enable row level security;
do $$ begin
  create policy "acesso via chave anonima" on produtos for all using (true) with check (true);
exception when duplicate_object then null; end $$;

-- ===== Tabela: empresa (perfil, 1 linha) =====
create table if not exists empresa (
  id int primary key,
  nome text default '',
  setor text default '',
  logo_url text default ''
);
insert into empresa (id, nome, setor, logo_url) values (1, '', '', '')
  on conflict (id) do nothing;
alter table empresa enable row level security;
do $$ begin
  create policy "acesso via chave anonima" on empresa for all using (true) with check (true);
exception when duplicate_object then null; end $$;

-- ===== Permissoes para a chave publicavel (role anon) =====
GRANT SELECT, INSERT, UPDATE, DELETE ON public.produtos TO anon;
GRANT SELECT, INSERT, UPDATE, DELETE ON public.empresa TO anon;

-- ===== Sincronizacao em tempo real =====
do $$ begin alter publication supabase_realtime add table produtos; exception when others then null; end $$;
do $$ begin alter publication supabase_realtime add table empresa; exception when others then null; end $$;
Segurança: com esta configuração, quem tiver a URL e a chave (ou o link de acesso) consegue ler e editar seus produtos. Para uso empresarial interno, basta não compartilhar o link publicamente. Se quiser login por senha depois, é só pedir.

3 Copiar a URL e a chave do projeto

No painel: Project Settings (engrenagem) → API:

  • Copie a Project URL (ex.: https://abc123.supabase.co).
  • Copie a anon public key (chave pública, não a service_role).
